# VASBC Website Scraper

A Python scraper that archives all public content from [vasbc.org](https://www.vasbc.org) into a local SQLite database.

## What it scrapes

| Section | Source pages | Content |
|---|---|---|
| **News** | `index.asp` → `popup.asp?serial=N` | Title + full article body |
| **Assembly** | `assembly.asp` | Date, speaker, topic, WAV sermon link; converts WAV → MP3 |
| **Articles** | `share.asp` → `viewdetail3.asp?serial=N` | Date, author, title, full content |
| **Missionary** | `preac.asp` → `viewdetail3x.asp?serial=N` | Date, author, title, full content |

## Features

- **Rate-limited** — 3-second (configurable) delay between every HTTP request
- **Progress bars** — per-section `tqdm` progress display
- **Resumable** — already-scraped items are skipped on re-runs
- **Audio download** — downloads WAV sermon files and converts to `YYYYMMDD.mp3` (requires `ffmpeg`)
- **Date normalisation** — Chinese dates like `2025年9月21日` are stored as `2025-09-21`
- **Portable schema** — SQLite with a schema designed for easy migration to PostgreSQL or MySQL

## Requirements

```
pip install requests beautifulsoup4 lxml tqdm pydub
```

For MP3 conversion, install [ffmpeg](https://ffmpeg.org/download.html) and ensure it is on your `PATH`.

## Usage

```bash
# Scrape all four sections (creates vasbc.db in the current folder)
python scrape_vasbc.py

# Scrape specific sections only
python scrape_vasbc.py --sections news assembly

# Custom database file and delay
python scrape_vasbc.py --db my_church.db --delay 10

# Custom MP3 output folder
python scrape_vasbc.py --audio-dir C:\sermons

# Preview page 1 of every section as JSON without writing to DB
python scrape_vasbc.py --dry-run
```

## Database schema

```
vasbc.db
├── news
├── assembly
├── writings        ← articles + missionary combined (distinguished by `type`)
└── scrape_log
```

### `news`

Stores each news article fetched from `popup.asp`.

| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER PK | Serial number from the URL |
| `title` | TEXT | Article headline |
| `content_html` | TEXT | Raw inner HTML of the content cell |
| `content_text` | TEXT | Plain-text version (whitespace stripped) |
| `scraped_at` | TEXT | ISO-8601 timestamp of when the row was written |

### `assembly`

Stores sermon/worship service metadata from `assembly.asp`. One row per service.

| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER PK | Auto-increment |
| `date` | TEXT | Raw site text e.g. `2026年5月10日_午堂崇拜講道` |
| `date_iso` | TEXT | Normalised `YYYY-MM-DD` |
| `speaker` | TEXT | Preacher name |
| `topic` | TEXT | Sermon topic/title |
| `wav_filename` | TEXT | Original WAV filename from the site |
| `wav_url` | TEXT | Full streaming URL (Big-5 percent-encoded) |
| `audio_mp3_path` | TEXT | Local path to converted MP3, or `NULL` if not yet downloaded |
| `scraped_at` | TEXT | ISO-8601 timestamp |

Natural dedup key: `(date, speaker, topic)`.

### `writings`

Articles (`share.asp`) and missionary reports (`preac.asp`) share this table, distinguished by the `type` column.

| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER PK | Serial number from the detail URL |
| `type` | TEXT | `'article'` or `'missionary'` |
| `date` | TEXT | Raw site text e.g. `2025年9月21日` |
| `date_iso` | TEXT | Normalised `YYYY-MM-DD` |
| `author` | TEXT | Author name / ministry role |
| `title` | TEXT | Article or report title |
| `content_html` | TEXT | Raw inner HTML of the content cell |
| `content_text` | TEXT | Plain-text version |
| `scraped_at` | TEXT | ISO-8601 timestamp |

Index: `idx_writings_type` on `(type)`.

### `scrape_log`

Audit log — one row per scraper run per section.

| Column | Type | Notes |
|---|---|---|
| `id` | INTEGER PK | Auto-increment |
| `section` | TEXT | `'news'`, `'assembly'`, `'articles'`, or `'missionary'` |
| `started_at` | TEXT | ISO-8601 start time |
| `ended_at` | TEXT | ISO-8601 end time, or `NULL` if still running |
| `items_new` | INTEGER | Rows inserted in this run |
| `items_skip` | INTEGER | Rows skipped (already in DB) |
| `status` | TEXT | `'running'`, `'done'`, or `'error'` |

## Notes

- The site uses **Big-5 / CP950** encoding (Traditional Chinese). The scraper forces this on every response.
- Several pages contain **malformed HTML** (`<tr>` nested inside `<td>`). The `lxml` parser is used because it repairs these the same way browsers do.
- WAV download links on assembly pages are generated by JavaScript at runtime. The scraper extracts the filename directly from the `<script>` block instead.
- If `ffmpeg` is not installed, all metadata is still saved; only the WAV→MP3 conversion is skipped. Re-run `--sections assembly` after installing ffmpeg to back-fill the MP3 files.
